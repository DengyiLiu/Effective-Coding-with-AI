# Final Project Rubric

| Category | Excellent | Needs Work |
| --- | --- | --- |
| Problem clarity | Names a real user and concrete problem. | Problem is vague or too broad. |
| Scope | Small enough to complete and demo. | Too large, unclear, or dependent on external setup. |
| AI workflow | Shows where AI helped and how the project author guided it. | Only says "we used AI" without process evidence. |
| Implementation | Working artifact is coherent and connected to the problem. | Artifact is incomplete or unrelated to the stated goal. |
| Verification | Includes tests, scripts, or a clear checking process. | No meaningful verification. |
| Reflection | Explains tradeoffs, limitations, and human judgment. | Reflection is generic or missing. |

## Reviewer Questions

- Does the project have a specific user?
- Is the problem concrete?
- Can the project author demo the result?
- Is there a verification step?
- Can the project author explain what AI did and what they decided?
