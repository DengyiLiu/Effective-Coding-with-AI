# Effective Coding with AI

## Course Context

This course focuses on practical AI-assisted software development workflows. The core workflow is planning, generating, testing, debugging, revising, and explaining software with clear evidence.

## Core Practices

- Write prompts with a clear goal, context, constraints, and output format.
- Provide relevant project files before requesting code.
- Use contracts, tests, scripts, and checklists to evaluate results.
- Debug generated code with evidence from errors and verification output.
- Keep software projects small enough to inspect and explain.
- Track AI assistance separately from human decisions.
