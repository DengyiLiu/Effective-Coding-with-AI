# Final Project Requirements

## Project Goal

Build a small software project that shows how AI assisted the coding workflow from planning to verification.

The project does not need to be large. It needs to be clear, testable, and explainable.

## Required Components

Each final project must include:

1. A clear problem statement.
2. A target user or use case.
3. A small working software artifact.
4. Evidence of AI-assisted planning or implementation.
5. A verification step, such as tests, a script, or a manual checklist.
6. A short final demo.
7. A short reflection explaining what AI helped with and what still required human judgment.

## Recommended Scope

Good projects are small enough to finish but real enough to evaluate.

Examples:

- A waitlist management dashboard.
- A study planner.
- A simple document summarizer.
- A data cleanup tool.
- A course resource search helper.

Avoid projects that require difficult setup, external authentication, payment systems, or production deployment.
