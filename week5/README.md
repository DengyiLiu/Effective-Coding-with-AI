# AIM 5012 Week 5

Topic: AI Coding Workflow on a Real Project.

Week 5 moves students from small, prompt-driven coding tasks into a controlled
AI coding workflow on an existing backend project.

Core project:

```text
Campus Room Booking API
Feature: Waitlist + Cancellation Promotion
```

Core course arc:

```text
contract -> context -> reconnaissance -> plan -> approval -> implementation
-> verification -> repair -> review -> decision log
```

## Course Position

Week 4 teaches students to read, run, change, and prove Python behavior.

Week 5 teaches students to use AI on an existing project without giving up
scope control, verification, or human judgment.

Week 6 can turn the Week 5 manual workflow into a small harness with state,
skill contracts, verification, review, and trace artifacts.
