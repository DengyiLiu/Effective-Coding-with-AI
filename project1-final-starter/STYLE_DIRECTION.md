# STYLE_DIRECTION.md

## Visual direction

Clean academic portfolio with a polished editorial feel.

## Design choices

- Use an off-white page background.
- Use dark text with high contrast.
- Use multiple accents sparingly: blue, teal, coral, and amber.
- Use 8px border radius for cards and buttons.
- Use strong spacing and clear section hierarchy.
- Avoid one-color themes, decorative blobs, and generic gradients.

## Layout goals

- Desktop: strong hero, two-column sections, project cards, visible workflow evidence.
- Mobile: single-column layout, readable text, no overlap.
- Every visual upgrade should connect to a course purpose.
