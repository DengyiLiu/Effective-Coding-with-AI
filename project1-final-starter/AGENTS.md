# Project 1 Final Portfolio Instructions

This project supports AIM 5012: Effective Coding with AI, Week 3.

Teaching goal: design a reusable skill step by step, use that skill to turn
the Week 2 portfolio skeleton into a stronger Project 1 portfolio, then
iterate the skill using a frontend design reference and compare three outputs.

Student-facing materials must stay in English.

Work rules:

- Read README.md, PROJECT_BRIEF.md, STYLE_DIRECTION.md, TEST_PLAN.md, SKILL_DESIGN_WORKSHEET.md, SKILL_TEMPLATE.md, and PROMPTS.md before editing.
- Design the project1-portfolio-polish skill before making large visual changes.
- Use the completed project1-portfolio-polish skill to inspect, plan, edit, test, and log.
- After the basic output works, use FRONTEND_DESIGN_REFERENCE.md to design a more opinionated project1-frontend-design-polish skill.
- Keep the project beginner-friendly: HTML and CSS only.
- Do not add frameworks, build tools, package managers, or advanced JavaScript.
- Keep any interaction small, visible, and testable; native HTML details/summary is enough.
- Make one meaningful change at a time.
- Explain which file changed and why.
- Test in a browser at desktop width, narrow mobile width, and one interaction.
- Update PROMPTS.md with accepted AI help, student decisions, and verification.
- Prefer 2-space indentation.

Quality target:

The final comparison should show why different skills produce different
outputs: starter page, basic portfolio skill output, and upgraded design skill
output.
