# Project 1 Final Starter

This is the Week 3 starting point. It is a Week 2-style portfolio skeleton
plus context files. It does not start with the finished skill. In class, you
will design the project1-portfolio-polish skill first, then use that skill to
make the Project 1 version.

Start here:

1. Open index.html in a browser.
2. Read AGENTS.md, PROJECT_BRIEF.md, STYLE_DIRECTION.md, TEST_PLAN.md, SKILL_DESIGN_WORKSHEET.md, and PROMPTS.md.
3. Read SKILL_TEMPLATE.md.
4. Open .agents/skills/project1-portfolio-polish/ and create SKILL.md from the template.
5. Validate the skill before editing the website.
6. Use the skill to inspect, plan, and then polish the Week 2 website.
7. Read FRONTEND_DESIGN_REFERENCE.md.
8. Design .agents/skills/project1-frontend-design-polish/SKILL.md.
9. Use the design skill to create a third output.
10. Compare starter, basic skill output, and design skill output.
