# TEST_PLAN.md

Run this checklist before calling the portfolio ready.

## Browser checks

- Open index.html in a browser.
- Confirm the headshot appears.
- Click About, Projects, Workflow, and Contact.
- Confirm each navigation link jumps to the right section.
- Resize to a narrow mobile width around 390px.
- Confirm project cards stack cleanly.
- Confirm no text overlaps or spills outside buttons/cards.
- Open and close the interactive details/summary element.

## Explanation checks

- Explain one HTML structure change.
- Explain one CSS visual change.
- Explain which instruction file or skill influenced the output.
- Explain how the interaction works.
- Update PROMPTS.md with the accepted change and verification.
