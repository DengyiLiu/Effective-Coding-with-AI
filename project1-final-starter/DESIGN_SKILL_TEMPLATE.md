# Project 1 Frontend Design Polish

Use this skill after the basic Project 1 portfolio already works.

## Read first

- FRONTEND_DESIGN_REFERENCE.md
- PROJECT_BRIEF.md
- STYLE_DIRECTION.md
- TEST_PLAN.md
- index.html
- style.css
- PROMPTS.md

## Workflow

1. State the subject, audience, and job of the page.
2. Propose a design thesis in one sentence.
3. Return a compact design plan before editing: palette, type roles, layout pattern, signature move, and risks.
4. Critique whether the plan is generic, too complex, or hard for a beginner to explain.
5. Wait for approval.
6. Edit index.html only if the structure needs to support the design thesis.
7. Edit style.css to apply the approved visual system.
8. Verify desktop and narrow mobile layouts.
9. Update PROMPTS.md with what changed and why the upgraded skill changed the output.

## Constraints

- Keep HTML and CSS beginner-friendly.
- Do not add dependencies, frameworks, build tools, or advanced JavaScript.
- Do not remove project evidence or AI workflow evidence.
- Do not make every section visually loud.
- Do not edit before returning the design plan and receiving approval.

## Output before editing

Return:

- Subject, audience, and page job.
- One-sentence design thesis.
- Palette with 4-6 named colors and purpose for each.
- Typography and layout plan.
- One signature design move.
- Generic-design critique.
- Browser verification checklist.
- Approval question.
